## 1. 界面总览

启动后访问 `http://localhost:3000`，编辑器由以下区域组成：

```
┌─────────────────────────────────────────────────────────┐
│  工具栏 (Toolbar)                                        │
├────────┬────────────────────────────────────┬───────────┤
│        │                                    │           │
│ 组件库 │         无限画布 (Canvas)           │ 属性面板  │
│ (左侧) │                                    │  (右侧)   │
│        │                                    │           │
├────────┴────────────────────────────────────┴───────────┤
│  状态提示栏                                              │
└─────────────────────────────────────────────────────────┘
```

- **工具栏**：撤销/重做、新建页面、预览、导出、AI Prompt 等
- **组件库**：按分类浏览组件，拖拽到画布
- **画布**：无限缩放/平移的工作区，放置页面画板和组件
- **属性面板**：编辑选中元素的详细属性

## 2. 页面管理

### 创建页面

点击工具栏 **「+ 页面」** 按钮，画布上会出现一个新的页面画板（默认 800×600）。

### 编辑页面属性

点击页面画板的**标题栏**选中它，右侧属性面板显示：

| 属性 | 说明 |
|------|------|
| 页面名称 | 显示在画板标题和预览顶栏 |
| 路由路径 | 如 `/home`、`/detail/:id`（支持动态参数） |
| 路由名 | 可选，用于命名路由 |
| 设为首页 | 勾选后该页面为预览入口页 |
| 折叠 | 折叠画板仅显示标题栏，节省画布空间 |
| X / Y / 宽 / 高 | 精确调整画板位置和尺寸 |

### 删除页面

选中页面画板后按 `Delete` 键。关联的连线会自动清除。

## 3. 组件操作

### 添加组件

1. 在左侧**组件库**中浏览或搜索组件
2. **拖拽**组件到目标页面画板内
3. 组件出现在画板上，自动选中

> 也可以直接将**图片文件**拖入画布，会自动创建 Image 组件。

### 组件库分类

| 分类 | 内容 |
|------|------|
| 基础 | Button、Input、Text、Image、Card 等 40+ 常用组件 |
| Aceternity UI | 渐变按钮、背景光束、流星、3D 卡片等动效组件 |
| React Bits | Shimmer、打字机、跑马灯、粒子等动画组件 |
| Shadcn | 命令面板、面包屑、数据表格等 UI 组件 |
| Uiverse | 纯 CSS 实现的按钮、加载器、卡片等 |
| 仪表盘 | KPI 卡片、环形图、流量表、任务看板等 |
| 动画背景 | 星空、海洋、极光、矩阵雨等全屏背景 |
| 3D 效果 | 翻转卡片、视差层、轨道环等 CSS 3D |
| R3F 场景 | Three.js 3D 场景（几何体、粒子等） |

### 悬停预览

鼠标悬停在组件库条目上 **0.3 秒**，会弹出实时预览浮窗。

### 选中与移动

- 单击组件选中（出现蓝色边框 + 缩放手柄）
- 拖拽移动位置（组件限制在所属页面画板内）

### 缩放尺寸

选中组件后，拖拽**四角/四边**的蓝色手柄自由调整大小。

### 层级控制

选中组件后，右侧属性面板提供层级按钮：

- ⬆️ 置顶（zIndex = 最大值 + 1）
- ↑ 上移一层
- ↓ 下移一层
- ⬇️ 置底（zIndex = 0）

### 复制粘贴

- `Ctrl+C`：复制选中组件（含类型、属性、尺寸）
- `Ctrl+V`：粘贴到当前选中的页面/组件所在页面

### 删除

选中组件后按 `Delete` 或 `Backspace`。

## 4. 连线与跳转

### 创建连线

1. 将鼠标移到组件右侧的**连接点**（小圆圈）
2. 按住拖拽到目标**页面画板**
3. 松开鼠标，连线创建成功

连线表示：「用户在该组件上触发事件后，跳转到目标页面」。

### 编辑连线属性

点击连线选中它，右侧属性面板显示：

| 属性 | 说明 |
|------|------|
| 连线模式 | **页面跳转**（默认）或 **滚动续页** |
| 触发事件 | onClick / onHover / onSubmit / onChange |
| 跳转参数 | key=value 格式，值支持 `${变量}` 占位符 |
| 需登录验证 | 勾选后预览中会弹出模拟登录框 |
| 守卫文案 | 登录提示文字 |

### 删除连线

点击选中连线后按 `Delete` 键。

## 5. 滚动续页模式

### 概念

传统模式下，每个页面画板是独立路由，点击跳转切换页面。

**滚动续页**模式下，多个页面画板合并为**同一个滚动长页**，用户上下滚动即可浏览，类似 PPT 全屏滚动效果。

### 使用方法

1. 创建多个页面画板（每个代表一屏内容）
2. 从第一个页面的组件连线到第二个页面
3. 选中连线 → 右侧面板 → 点击 **「↓ 滚动续页」**
4. 继续连线：第二个页面 → 第三个页面（也设为滚动续页）
5. 预览时，这些页面自动合并为 scroll-snap 滚动容器

### 视觉区分

| 连线类型 | 样式 |
|----------|------|
| 页面跳转 | 灰色实线 + 事件标签 |
| 滚动续页 | **紫色虚线** + "↓ 滚动续页" 标签 |

### 预览效果

- 每页占满一屏高度
- 滚动时自动吸附到下一屏（scroll-snap）
- 顶栏显示 "↓ 滚动模式 (N页)" 标识
- 导航到滚动组内任何页面都会从第一屏开始

### 典型场景

- 产品落地页（Hero → 功能介绍 → 定价 → CTA）
- 活动宣传页
- 个人作品集

## 6. 属性编辑

选中组件后，右侧面板显示该组件的可配置属性：

### 通用属性

| 属性 | 说明 |
|------|------|
| X / Y | 组件在页面内的位置 |
| 宽 / 高 | 组件尺寸（也可通过拖拽手柄调整） |
| 层级 | zIndex 控制 |

### 组件专属属性

不同组件有不同的可配置项，例如：

- **文本** (text)：按钮文字、标题内容
- **主题色** (color)：从预设色板选择
- **动画速度** (speed)：数值越大越快
- **图片地址** (imageSrc)：Image 组件的图片 URL

修改后按 **Enter** 或点击其他区域即可生效，也可点击 **「✓ 保存属性」** 按钮确认。

## 7. 画笔工具

点击画布顶部工具栏的 **「画笔」** 按钮进入绘制模式。

### 绘制形状

| 模式 | 说明 |
|------|------|
| 自由 | 手绘任意路径 |
| 直线 | 两点连线 |
| 矩形 | 拖拽画矩形 |
| 椭圆 | 拖拽画椭圆 |
| 箭头 | 带箭头的直线 |
| 三角 | 等腰三角形 |

### 画笔设置

- **颜色**：黑/红/蓝/绿/紫 5 色可选
- **粗细**：细(1px) / 中(2px) / 粗(4px)

### 退出画笔

再次点击「画笔」按钮退出，恢复正常拖拽模式。

绘制完成后，图形作为 **Freehand** 组件保存在页面中，可移动/缩放/删除。

## 8. 预览

点击工具栏 **「预览」** 按钮，在新标签页打开预览界面。

### 预览功能

- **交互跳转**：点击有连线的组件，跳转到目标页面
- **滚动续页**：scroll 模式的页面自动合并为滚动长页
- **登录守卫**：标记 requireAuth 的跳转弹出模拟登录框
- **设备切换**：桌面 / 手机（390×720）两种视口
- **Section 动画**：AnimSection 组件支持 fade-up / slide-left 等入场动画

### 预览入口

预览从标记为「设为首页」的页面开始。如未设置，默认使用第一个页面。

## 9. 导入导出与 AI

### 导出 JSON

- 工具栏 **「导出」**：下载 `.json` 文件
- 工具栏 **「复制」**：复制 JSON 到剪贴板
- `Ctrl+S`：快捷导出下载

### 导入 JSON

工具栏 **「导入」** → 选择之前导出的 `.json` 文件，画布恢复完整状态。

### AI Prompt

点击工具栏 **「AI Prompt」**：

1. 系统自动将当前画布包装为结构化 Prompt
2. 可直接复制给任何 AI 助手生成代码
3. 也可配置 OpenAI API Key 后点击「AI 生成」直接获取结果

> API Key 仅存储在浏览器 localStorage，不会上传到任何第三方服务器。

## 13. 常见问题

### Q: 组件拖不进去？

确保目标页面画板处于**展开**状态（非折叠）。组件只能拖入展开的画板内。

### Q: 预览看不到效果？

- 确保至少有一个页面被设为「首页」
- 预览读取的是 localStorage 中的数据，编辑后刷新预览页即可

### Q: 滚动续页不生效？

- 确保连线模式已切换为「↓ 滚动续页」（紫色虚线）
- 滚动链必须从第一个页面开始连续连接（A→B→C）
- 预览时从链头页面进入

### Q: 数据存在哪里？

所有数据存储在浏览器 **localStorage** 中。清除浏览器数据会丢失画布。建议定期使用「导出」备份 JSON 文件。

### Q: 如何协作？

目前为单机版本。可通过导出/导入 JSON 文件在多人间传递。设置 `NEXT_PUBLIC_CLOUD_API` 环境变量可对接自建云端同步服务。

### Q: 组件尺寸怎么调？

选中组件后拖拽四角的蓝色手柄即可自由缩放，无需选择预设尺寸。也可在右侧属性面板精确输入宽高数值。
